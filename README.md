# 人體消化大冒險

2026-10-26 本機優化版。雙擊 `index.html` 即可離線遊玩；以靜態伺服器或 GitHub Pages 開啟時，會驗證並載入 `questions.json`。讀取失敗、格式錯誤或逾時 3 秒，繼續使用完整內建題庫。遊戲開始後固定使用該局的題庫快照。

## 個人學習

- 短程（點數加倍）或完整旅程；途經五區終點必有檢核，不因擲骰跳過。
- 首次答對 +20 學習分。答錯不扣分、不退格，解析後重答一次。
- 重答與錯題複習不重複加分，首次正確率保留；尚未修正的題目可在旅途中或結算後複習。
- 膽汁事件改為前進 2 格；慢行站改為觀察與複習。

## 小組同機競賽

- 支援 2–4 組，單一裝置輪流操作，並非多裝置連線。
- 公平回合：每隊 8、12 或 16 回合，依學習分排名，同分並列。地圖位置與冒險獎勵不影響此排名。短局不保證走完所有器官，未作答區會標示「待探索」。
- 終點競速：有隊抵達後，其他隊完成同一輪再結算；同輪抵達者並列完賽。
- 每個基本回合恰好一題。加擲由同隊執行，只移動，不連鎖觸發事件或增加題數。
- 慢行事件：下回合不移動，但保留一題，避免失去作答機會。
- 各隊獨立保留作答、錯題與成績。小組模式不啟用個人適性降難度，避免不同隊伍因連錯而取得不同難度規則。
- 題目仍隨機抽選，未做統計等值化；競賽結果適合作為課堂回饋，不宜直接當成標準化測驗分數。

## 課堂操作

- 每題可選不限時、20 秒、40 秒；教師可暫停，切至背景自動暫停。
- 自動保存當局狀態（包括題目選項、剩餘時間），回到設定可續玩。瀏覽器來源不同或清除瀏覽資料後無法共用存檔。
- 存檔鍵 `digestive_adventure_v2`；目前只保留最新一局，開始新局前提醒取代。原版沒有存檔，因此沒有舊版進度可遷移。
- 結算顯示全隊、各器官正確率與錯題；可下載 JSON 紀錄、列印或另存 PDF。
- 識別碼僅供區分紀錄，不具防偽功能。預設只保存於瀏覽器；個人版結算可由學生點擊「送出個人學習成績至試算表」，透過原有 GAS 端點提交姓名、班級座號與學習成績。小組版提供全隊下載與文字備份，不冒用個人身分送出。
- 投影使用左右布局，小螢幕上下排列；支援大字、地圖放大、鍵盤操作及瀏覽器縮放。

## 檔案與驗證

- `core.js`：純遊戲狀態與規則；`game.js`：畫面、計時、存檔與匯出。
- `questions.json` 與 `data-embedded.js` 必須同步。測試會比對兩份資料。
- `map-data.js`：54 格座標；`map.jpg` 保留原圖。慢行、細菌與水分事件已對齊第 40、43、52 格。
- 執行 `node tests/regression.cjs`：12 組核心檢查，包含 300 局隨機回歸。
- 執行 `node tests/browser-state.cjs`：外部題庫錯誤、逾時與儲存不可用的回退測試。
- 保留專屬題庫，不依賴其他大廳或中央題庫。

本次題目校訂包含：oral_01 未定義選項、li_04 腹瀉單一歸因、si_08 藥物作用位置，以及食道／大腸分泌與葡萄糖運輸的措辭。題庫整體仍以國中課程簡化模型為基礎，非完整醫學生理教材。

本機修改不等於已推送 GitHub 或已部署。

## 與既有成績元件整合

保留整合時原專案的 BioGameSuite v4.2 成績元件、暖色主題及交機檢核。由本遊戲的模式選擇畫面負責開局，個人版保留 701–710、01–35 選單、全名必填與身分／公約確認；不讓共用元件的自動個人登入遮住小組入口。

提交的是「學習分」，不是含運氣獎勵的 ATP。只有收到 HTTP 成功及 JSON `success: true` 或 `status: "success"` 才顯示收件確認；斷線、逾時、錯誤或不相容回應均提示備份，不宣稱已寫入試算表。仍需實際後端核對，開發驗證不提交測試成績至正式試算表。

交機清除會一併移除本遊戲存檔；返回錯題複習會取消成績元件的三分鐘重置計時，避免複習中意外刷新。新增元件選項為向後相容擴充，未修改其他遊戲的共用檔案。
